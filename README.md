# PLAY CHORD
> 코드 재생 웹 서비스

<br/>

## 📝 프로젝트 소개

연구실 과제로 진행했던 자동 작곡 서비스와 연동하기 위해 제작한 웹 서비스입니다.
MIDI 파일을 불러와 코드(Chord)를 재생하거나, 입력한 코드를 MIDI 파일로 내보낼 수 있습니다.

<br/>

## 주요 기능

- **코드 재생** - 입력한 코드를 확인하고 재생할 수 있습니다.
- **재생 설정** - 템포, 박자, 옥타브를 설정할 수 있습니다.
- **MIDI 내보내기** - 입력한 코드를 MIDI 파일로 저장할 수 있습니다.
